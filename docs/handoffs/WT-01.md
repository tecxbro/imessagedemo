# WT-01 handoff

## Delivered exports

`src/compiler/index.ts` exports:

- `validateDemo(input: unknown): ValidationResult`
- `compileDemo(demo: DemoFlow): CompiledDemo`

Both replace the `NOT_IMPLEMENTED` stubs. `validateDemo` accepts one frozen `DemoFlow` and returns it unchanged in meaning. `compileDemo` returns one platform, with message events in source order, then a draft event and a typing event at `atMs: 0`.

Playback `atMs` is `message.atMs - messages[0].atMs`. Equal authored times stay equal and keep array order. `durationMs` is the max of those offsets and the end of the last text arrival window. Windows come from `src/contracts/motion-tokens.json`: send `690`, receive `300`, and `bubbleEffectDuration` for slam, loud, and gentle. An effect replaces the shell flight. Invisible ink and non-text media do not take the channel. Text is copied exactly. A photo caption stays on the image message; compile does not insert another message.

Diagnostics use the frozen `{ path, message }` shape. `path` is a JSON pointer. `message` starts with a stable code: `UNSUPPORTED_COMPONENT`, `CATALOGUE_ONLY`, `UNKNOWN_FIELD`, `MISSING_FIELD`, `INVALID_TYPE`, `INVALID_VALUE`, `INVALID_TIMESTAMP`, `DUPLICATE_ID`, `INVALID_REFERENCE`, `OVERLAPPING_ARRIVAL`, `INVALID_ANIMATION`, `INVALID_ASSET`, `PLATFORM_MISMATCH`, or `CONTRACT_GAP`.

## Source limitations

- Pinned `MessageKind` includes `typing`. The frozen demo kind does not. Typing stays on `DemoFlow.typing`.
- `system` and FaceTime are catalogue-only standalone components. A poll or mini-app is `UNSUPPORTED_COMPONENT`. There is no fallback text or card.
- Screen effects, the effects picker, and the other catalogue-only ids are not compiled.
- Asset checks are lexical: local image and attachment names must stay inside a relative asset root, and link destinations must be `http:` or `https:`. `validateDemo` does not stat files or fetch URLs. Existence remains CLI preflight.
- `iosScreenTransition`, `screenEffectDuration`, and the macOS transition tokens are unverified in `motion-tokens.json` and are not used to accept or reject a compile.

## Integration readiness

WT-02 can call `compileDemo` on a `DemoFlow` that `validateDemo` accepted. The compiled value is JSON data: one of `ios` or `macos`, no `Date`, no function, no absolute path. Timeline offsets are authored deltas, not the test double's `index * 1000` spacing. `durationMs` includes the trailing arrival window from the frozen tokens. Draft and typing are events at `0`, after the message events. Do not expect `NOT_IMPLEMENTED` from these two functions.
